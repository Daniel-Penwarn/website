# Sample Website

This is a sample website made as part of [*Learn Enough Git to be Dangerous*] (https://www.learnenough.com/git-tutorial) 

After finishing *Learn Enough Git to be Dangerous, you'll know enough Git to be *Dangerous*. This means you'll be able to use Git to track changes with your projects, back up data, share your work with others, and be able to collaborate with programmers and other users of Git.

For more information on Git, see the
[official Git documentation] (https://git-scm.com/).
